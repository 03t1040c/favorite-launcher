Search Launcher Edge履歴連携拡張機能

初回設定:
1. Search Launcherの最新版を一度起動します。
2. このZIPを任意のフォルダへ展開します。
3. Edgeで edge://extensions を開きます。
4. 「開発者モード」を有効にします。
5. 「展開して読み込み」を押し、展開したedge-extensionフォルダを選択します。

以後は新しい訪問時に履歴を送信します。定期確認の間隔はアプリの設定に従い、既定は30秒です。
拡張機能のボタンから、現在のページを直接お気に入り登録することもできます。
従来のHistoryファイル読み込みも引き続き利用できます。

ストア公開用:
outputs/favorite-launcher-edge-store.zip が提出用パッケージです。
公開手順、必要な登録情報、ストア版の初回接続設定は STORE-SUBMISSION.md を参照してください。
このZIPを作成しただけではストアからインストールできません。公開申請と審査が必要です。
