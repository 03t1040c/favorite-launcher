# Edge Add-onsへの提出

## 提出するファイル

`outputs/favorite-launcher-edge-store.zip` を使用します。開発者モード用の固定keyはストア版から除外しています。ストア版のIDは開発版と異なる可能性があるため、インストール後に拡張機能のポップアップでIDをコピーし、アプリの設定の「ストア版IDを登録」に貼り付けてください。

ストア版への切り替え時は、開発版を無効化・削除して二重送信を防ぎます。アプリに保存済みのお気に入りは残ります。

## 登録情報の案

名前：Favorite Launcher Edge連携

目的：Edgeの閲覧履歴と、ユーザーが選択したページを、同じPCのFavorite Launcherへ渡して検索・お気に入り登録を行う。

説明：閲覧履歴をローカルアプリへ自動連携します。ツールバーのボタンから、現在表示中のページを履歴の反映を待たずにお気に入りへ追加できます。別途Windows版Favorite Launcherのインストールが必要です。履歴情報を外部サーバーへ送信しません。

公開範囲：自分用・限定配布ならHidden。検索一覧には表示されませんが、URLを知っている人は導入できます。

## 権限の理由

- history：閲覧履歴と訪問イベントを取得して、ローカルアプリの検索へ反映するため。
- nativeMessaging：同じPCのFavorite Launcherと通信するため。
- storage：前回の同期時刻をローカルに保持するため。
- alarms：ブラウザー起動中に取りこぼした履歴を定期的に再取得するため。
- activeTab：ユーザーが拡張ボタンを押したとき、そのページのURLとタイトルを保存するため。

外部コードの読み込み：なし。

## 審査時に必要な準備

提供者名、問い合わせ先、公開されたプライバシーポリシーURL、説明画像を申請者が用意してください。PRIVACY.mdは確認・公開用の文案です。サポート連絡先や公開URLを架空の内容で埋めないでください。

審査担当者へWindowsアプリの入手先と、アプリを一度起動してストア版IDを登録する手順を案内してください。アプリ側はストア版IDを許可するNative Messaging設定を登録します。

履歴の定期同期はChromiumのアラーム仕様により最短30秒です。ページ訪問時はすぐ送信され、起動中のアプリは約1秒間隔で到着を確認します。

公式手順：https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension
